# Volume 7 sources

Each folder holds one piece engraved by a volunteer of the Mutopia Project
(https://www.mutopiaproject.org), upgraded with `convert-ly` and cleaned by `course/rep7.py`
(headers, paper settings, MIDI output and forced line breaks removed; a few engraving slips fixed, as
listed in the main README under "Book 7A (done)"). `SOURCE.txt` in each folder names the original
Mutopia file, its typesetter and its licence.
